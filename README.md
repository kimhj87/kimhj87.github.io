# 주간보고 사이트 안내

재택근무 직원용 주간보고 + 파일 첨부 사이트입니다.
Supabase(DB·로그인·파일 저장)와 정적 웹호스팅만으로 돌아갑니다. 서버를 따로 둘 필요가 없습니다.

## 폴더 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 사이트 화면 |
| `config.js` | Supabase 주소와 키 (입력 완료) |
| `supabase/schema.sql` | DB 테이블, 보안 규칙, 파일 저장소 설정 (이미 적용됨, 새 프로젝트에 다시 설치할 때만 사용) |
| `supabase/functions/signup/index.ts` | 회원가입 서버 함수 (이미 배포됨) |

---

## 현재 상태
- Supabase 프로젝트 **staff-portal** (서울, 무료 플랜)에 DB·보안 규칙·파일 저장소·회원가입 함수까지 **설치 완료**
- `config.js`에 주소와 키 **입력 완료**
- 회원가입은 서버 함수(`supabase/functions/signup`)로 처리해서, 대시보드에서 이메일 확인을 끌 필요가 없습니다.

## 2단계. 대표 계정 만들기
1. 사이트에서 **회원가입**을 합니다(대표님 이름, 아이디, 비밀번호). "승인 대기" 화면이 나오면 정상입니다.

   ```sql

   ```
3. 새로고침하면 대표 화면(주간보고 / 직원)이 나옵니다.

## 직원 사용 흐름
1. 주소 접속 → 오른쪽 위 **로그인** → **회원가입**(이름, 아이디, 비밀번호)
2. 대표가 **직원** 탭에서 **승인**
3. 로그인하면 첫 화면에 **내 보고서 목록**이 나옴(누르면 전체화면, 거기서 [수정하기]·[삭제])
4. 오른쪽 위 **✎ 작성하기** → 제목 / 보고 날짜(달력 또는 [오늘]·[어제]·[1주 전]) / 이번 주 한 일(한 칸에 통합) / [+ 파일 추가] → **[제출하기]** 한 번으로 보고서와 파일이 함께 올라감
5. 제출이 끝나면 방금 낸 보고서가 전체화면으로 열림

## 게시판 (직원·대표 공용)
- 상단 가운데 메뉴(휴대폰은 아래 탭 바)에서 **게시판**을 누릅니다.
- **글쓰기**(오른쪽 위) → 제목·내용 등록. 글을 누르면 내용과 댓글이 보이고 아래에서 댓글을 답니다(Ctrl+Enter로 등록).
- 글과 댓글에 **파일을 첨부**할 수 있습니다(여러 개, 파일당 50MB). 댓글은 파일만 올려도 됩니다. 첨부 파일은 승인된 직원 모두 [보기]·[받기]가 됩니다.
- 본인 글은 수정·삭제, 본인 댓글은 삭제할 수 있습니다.
- 대표는 모든 글·댓글을 삭제할 수 있고, 글쓰기에서 **공지로 상단에 고정**을 켤 수 있습니다.
- 대표는 글 화면의 [날짜 수정]과 댓글 옆 [날짜 수정]으로 **글·댓글 쓴 날짜를 바꿀 수 있습니다**(목록 순서와 "n시간 전" 표시도 그 날짜 기준). 직원은 바꿀 수 없습니다.
- 글쓴이 이름은 승인된 직원끼리만 보입니다(아이디는 안 보임).

## 대표 기능
- **직원**: 가입 승인·승인 취소. 퇴사자는 승인 취소하면 바로 차단되고, 기록은 남습니다.
- **주간보고**: 올라온 보고서를 **제출한 날짜별로 전부** 한 화면에 표시(최신 날짜가 위). 각 보고서에 제목·보고 날짜·내용·첨부 파일 표시. 직원 필터, 보고서마다 [전체화면], 보고서 제출일·파일 올린 날짜 수정(수정하면 그 날짜 묶음으로 이동), 파일 [보기]·[받기]
- **엑셀 다운로드**: 주간보고 목록(제출일시·보고 날짜·이름·제목·이번 주 한 일·첨부 파일)과 첨부파일 목록을 `주간보고_YYYY-MM-DD.xlsx`로 저장(직원 필터 적용)

## 보안 구조
- 모든 권한은 Supabase 서버의 보안 규칙(RLS)으로 막습니다. 화면만 숨기는 방식이 아닙니다.
- 직원은 **본인 기록만** 볼 수 있고, 다른 직원 기록은 볼 수 없습니다.
- 직원은 보고서 제출일과 파일 올린 날짜를 **바꿀 수 없습니다**. 대표만 자유롭게 바꿀 수 있습니다.
- 승인 전 계정은 아무것도 읽거나 쓸 수 없습니다.

## 자주 묻는 것
- **직원이 비밀번호를 잊었을 때**: Supabase → Authentication → Users에서 해당 사용자(`아이디@staff.portal.app`)를 찾아 비밀번호를 새로 설정해 주세요.
- **파일 용량**: 파일당 50MB입니다. 늘리려면 `schema.sql`의 `52428800`과 `config.js`의 `MAX_FILE_MB`를 같이 바꾸세요. Supabase 전체 업로드 한도(Storage 설정)도 확인해야 합니다.
- **한글(hwp) 파일**: 올리고 받을 수 있습니다.
- **무료 플랜 한도**: 파일 저장 전체 1GB, DB 500MB입니다. 넘으면 Supabase Pro(월 $25)로 올리면 됩니다.
- **일시정지**: 무료 플랜은 7일 동안 아무도 접속하지 않으면 일시정지됩니다. 매주 보고서가 올라오면 보통 문제없지만, 명절처럼 1주 넘게 아무도 안 들어오면 멈출 수 있습니다. 멈추면 Supabase 대시보드에서 Restore를 누르면 됩니다(데이터는 그대로).
